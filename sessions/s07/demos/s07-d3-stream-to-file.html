S07-D3: From a stream to a file

What this shows: reassembly turns the pieces of a file inside packets into one stream, and file carving then cuts the file out of that stream by its file signature.

One TCP conversation: 192.0.2.10 sending to 203.0.113.80

The tool knows the protocolFor example HTTP. The tool does steps 3 to 8 for you. Wireshark: Export Objects.
The tool does not know itYou do steps 3 to 8 by hand, as you did here.

Keyboard: the left and right arrow keys move between steps.

WHAT YOU JUST SAW

Six pieces in arrival order became one stream in the order the sender wrote it, and a file was carved from that stream by its file signature. This is reassembly, followed by the file carving you did on a disk, now applied to a new source. It matters because a file recovered from traffic is evidence of what crossed the wire. A missing packet leaves a hole in the file, so check that the stream is complete before you rely on it.
