S11-D5: The digest chain

What this shows: each hourly digest file holds the hash value of every log file and the signature of the digest before it, so a changed log file, a removed log file, a removed digest and a forged digest are each detected.

Keyboard: the left and right arrow keys move between steps.

WHAT YOU JUST SAW

Each kind of tampering was caught by a different part of the design: a changed file by its hash value, a removed file by the digest that lists it, a removed digest by the chain of previous signatures, and a forged digest by AWS's signature. The limits matter as much: validation proves that CloudTrail's files are unchanged since delivery, not that every action was recorded, and it does not cover the server access logs. This is section 7's sealed evidence bag, built on the hash values of Session 1, and it is why your trail has log-file integrity validation switched on before the incident.
