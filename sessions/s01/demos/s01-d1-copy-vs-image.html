What this shows: a file copy takes only what the file system lists, but a forensic image takes every sector of the device.

Keyboard: the left and right arrow keys move between steps.

WHAT YOU JUST SAW

A file copy and a forensic image of the same card are different things. The copy followed the index and took 11 sectors. The image ignored the index and took all 24, including the older data and the unused space.

This is why the unit images first and then works on the image: evidence can sit in sectors that a file copy never visits. Session 2 shows what those sectors can hold.
