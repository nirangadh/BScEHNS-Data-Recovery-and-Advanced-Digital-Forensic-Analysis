S01-D2: One bit changes the whole hash value

What this shows: flipping a single bit of the data gives a completely different SHA-256 hash value, while the size and the name of the file stay the same.

Your turn. Choose a byte and a bit, then flip it. With a mouse you can also click any bit in the picture.

Keyboard: the left and right arrow keys move between steps.

WHAT YOU JUST SAW

One bit out of 80 changed, and about half of the 256 bits of the hash value changed with it. A small change in the data never gives a small change in the hash value. When the bit went back, the old value came back exactly.

The file name and the size stayed the same the whole time, so they cannot be used to show that data is unchanged. This is why the unit records a hash value at acquisition and calculates it again before every examination: any change at all, anywhere in the image, will show.
