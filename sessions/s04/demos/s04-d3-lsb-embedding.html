S04-D3: Hiding a letter in the last bits of a picture

What this shows: writing message bits into the least significant bit changes a colour value by at most one, which no eye sees and a comparison shows at once.

THE MESSAGE: THE LETTER H, AS EIGHT BITS

THREE PIXELS OF THE PICTURE (THE BAR SHOWS THE COLOUR BEFORE AND AFTER)

Keyboard: the left and right arrow keys move between steps.

WHAT YOU JUST SAW

One letter, eight bits, went into the last bits of eight colour values. Each value either stayed the same or moved by one. The three pixels look exactly as they did before.

This is why the method is hard to see and easy to prove. The picture's hash value has changed, a comparison with the original shows every changed value, and anyone who reads the last bits in the same order gets the message back. In the lab you use all three facts: the hash value, the comparison, and a tool that tries the common orders.
