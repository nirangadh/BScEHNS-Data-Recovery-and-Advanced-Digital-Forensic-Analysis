WHAT YOU JUST SAW

A second content was added to the record of a file, as a named $DATA attribute. The ordinary views did not change: the listed size, the content that opens and the hash value of the file all describe the first content only.

A forensic tool reads the record and lists both. So on an NTFS volume you list the streams of every file as a routine step, you hash a stream as its own item, and you remember that two files with the same hash value can still differ in their streams. Most streams are ordinary: Windows adds one to every file that comes from the internet.
