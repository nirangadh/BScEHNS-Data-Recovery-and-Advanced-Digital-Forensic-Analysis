What this shows: each change adds a whole page to the write-ahead log, and a checkpoint keeps only the newest version.

WHAT YOU JUST SAW

Each change added a full copy of a page to the write-ahead log, and the shm file pointed readers to the newest copy. Older versions stayed in the log and in the database file until a checkpoint copied only the newest versions into the database; after that, the log was reused from its start and each new frame overwrote an old one. An older version of a row lives only as long as the frame that holds it.

For the investigation: a WAL is a history of pages, not of rows. Compare a page's versions frame by frame, and say which frame and commit a recovered value came from. Back to section 3 of the notes.
