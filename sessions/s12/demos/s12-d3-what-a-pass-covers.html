S12-D3: What a pass covers

What this shows: one validate-logs run checks only the log files that one Region's digests list from the start time, so the newest files, other Regions and the server access logs stay outside its pass.

Command:

CLOUDTRAIL LOG FILES IN AP-SOUTH-1, BY HOUR (DIGEST AT EACH HOUR'S END)

CLOUDTRAIL LOG FILES IN US-EAST-1

SERVER ACCESS LOG FILES

Green: checked and valid. Dashed: in your collection, not checked by this run. Each square is a log file named by the hour it was delivered in. Times are invented, in UTC.

Keyboard: the left and right arrow keys move between steps.

WHAT YOU JUST SAW

One validate-logs run checked only the files that the digests of one Region listed from its start time. The newest files waited for the next digest, the other Region needed its own run, and the server access logs were never covered at all. Unchecked is not invalid, and valid is not complete. This is section 5: in the lab you run the command once per Region, compare its counts with your collection, and state that the access logs have no such check.
