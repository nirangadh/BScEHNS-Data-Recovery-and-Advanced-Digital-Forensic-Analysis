WHAT YOU JUST SAW

The partition table is a few bytes in one sector. It lists ranges of sectors, and the operating system believes it completely. When an entry is removed, the operating system stops showing that range, but not one sector inside the range changes.

For the investigation this means two things. Sectors that the table does not cover, at the start, at the end or in the middle of a disk, must be examined and not assumed empty. And a volume that has "disappeared" can often be found again, because its file system still starts where it always did. Session 3 shows the tool that does this.
