WHAT YOU JUST SAW

The same file was deleted on two devices. On the hard disk, the content stayed until new files happened to need its clusters. That took time, and it happened one cluster at a time, so for most of the hour the file was recoverable in part. On the solid-state drive, the operating system sent TRIM at the moment of deletion, and within minutes every block of the file read as zeros.

On both devices the record of the file survived, with its name, size and dates. For the investigation this means that speed matters: the sooner a device is imaged, the more content remains. It also means that a recovered file must always be checked with a hash value, because a file that has lost one cluster looks complete in a file list.
