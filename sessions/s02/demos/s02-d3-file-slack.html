S02-D3: File slack

What this shows: a shorter file written into a used cluster leaves old data after its own end.

SECTORS 1 TO 8 OF THE CLUSTER

New fileRAM slack (zeros)Old data

Keyboard: the left and right arrow keys move between steps.

WHAT YOU JUST SAW

A file system gives out whole clusters and does not clean them first. When a new file ends before the end of its last cluster, the rest of that cluster is file slack. The short strip up to the end of the sector is RAM slack, which modern Windows fills with zeros. The whole sectors after it are drive slack, and nothing writes to them, so they keep the data of the file that used the cluster before.

For the investigation this means that a current, innocent file can carry the tail of a deleted one. A normal copy never shows it, because the operating system stops reading at the end of the file. A forensic image holds it, and a search of the image can find it.
