WHAT YOU JUST SAW

The same file was deleted three times. Each file system changed a few small fields in its index and marked three clusters as free. None of them touched the content. That is why deletion takes a moment, however large the file is.

The fields that each file system keeps decide how recovery starts. NTFS keeps the full list of runs, so a tool can follow it. FAT32 keeps only the first cluster, so a tool must assume that the file was stored in one run. ext4 clears the list, so a tool must look in the journal or search the unallocated space. In every case the content waits in unallocated space until something else is written there.
