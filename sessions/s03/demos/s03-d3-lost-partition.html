What this shows: a boot sector describes its own volume, so a scan that finds it can rebuild the missing entry of the partition table.

WHAT YOU JUST SAW

The partition table listed one partition and left more than half of the disk without an owner. The scan read that space sector by sector and tested each sector: is this the start of a file system? One sector passed the test. It was a boot sector, and it stated the type and the size of its own volume. The place where it was found gave the start. Those three facts are everything that an entry in the table holds, so the entry could be written again.

Nothing in the volume changed at any point. The files were there before the scan and after it. Only sector 0 is different at the end. For the investigation this means two things: a volume that is missing from the table is still evidence, and writing the table back is a change, so you do it on a working copy or you read the volume from its start sector and write nothing.
