WHAT YOU JUST SAW

The message was cut into stripes of four characters, and the stripes were written to two disks in turn. Each disk alone held every second stripe and could not be read. Reading the disks back in the order and with the stripe size that were used to write them gave the message exactly. Every other setting gave a wrong result. With the wrong stripe size, the first characters were still right, so the result looked like a good start and was wrong after that.

A stripe carries no number and no sign of where it belongs. The order of the disks and the stripe size are facts about the set, kept outside the data. For the investigation this means that you record which slot each disk came from before you remove it, you image every disk separately, and you rebuild the set from the images.
