WHAT YOU JUST SAW

A registry key keeps a single last-write time. Every change to the key, to any of its values, moved the same stamp and wiped out the time before it. So the time tells you when the key last changed and never which value changed, unless the key holds an order list that names its newest value. In the case, this is why the key RunMRU dates only the newest command that the suspect typed, and why a report must not give one time to every value in a key.
