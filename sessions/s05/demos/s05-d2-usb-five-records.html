S05-D2: One USB stick, five records

What this shows: each artefact holds one fact about a USB stick, and only the device serial number joins the facts into one story.

Keyboard: the left and right arrow keys move between steps.

WHAT YOU JUST SAW

No single artefact holds the history of a USB device. Each record was made for one job, so each answers one question: which device, first connected when, which drive letter, under which account. The device serial number is what joins them, and it must be read to the last character, because the company's stick and the suspect's stick differ only from the ninth. One of the five records uses local time, so it cannot be compared with the others until it is normalised to UTC.
