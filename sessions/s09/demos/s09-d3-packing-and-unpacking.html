S09-D3: Packing, and unpacking

What this shows: packing raises the entropy of one PE section, empties another in the file, and hides the imports behind a few functions; unpacking brings them back.

PE sections: entropy (0 to 8), size in the file and in memory

    Keyboard: the left and right arrow keys move between steps.

    WHAT YOU JUST SAW

    Packing moved the whole program into one dense PE section, left an empty PE section to unpack into, and replaced a telling import list with the few functions the unpacking code needs. Each change hides something that sections 3 and 4 of the notes read. Unpacking with a tool that knows the packer brought the PE sections, the imports and the strings back, as a new file with its own hash value. When no such tool exists, the honest note is that the contents are not visible statically.
