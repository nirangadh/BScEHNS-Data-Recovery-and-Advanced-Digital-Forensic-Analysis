WHAT YOU JUST SAW

    
YARA did exactly what each YARA rule said. One string matched every file that carried it, including a different program and an analyst's notes, and missed the related program that keeps the string encoded. The MZ check removed the text file, and asking for two of three strings that the target family carries removed the other program and recovered the newer version. That miss was fixed only because the newer version still carried two of the strings: a YARA rule never finds a string that is not in the file. Section 7 of the notes: write from specific features, add structure, and test against every file you have.
