WHAT YOU JUST SAW

    
capa matched patterns, function by function: a call to CreateService made "create service" true, and the same call together with the number 2 in one function made "persist via Windows service" true. Nothing ran, so the report says what the code can do, not what it did. When the author hid the call behind GetProcAddress, the feature disappeared and so did the capability. Section 6 of the notes: a capability is not an action, not proof of intent, and never a complete list.
