S09-D1: A program file, opened layer by layer

What this shows: a PE file is a map of pointers. The file signature leads to the PE header, the PE header to the PE sections, and a table to the imports, so the structure, not the name, says what the file is and what it is built to do.

WHAT YOU JUST SAW

You opened a made-up program file the way Windows and an analyst do: the two letters MZ, then a pointer to the PE header, then the PE sections, then the import list. Every step followed a value written inside the file, and the name of the file played no part. That is section 3 of the notes: the structure tells you what the file is, the imports tell you what it is built to do, and the compile timestamp is a claim that you check against other dates.
