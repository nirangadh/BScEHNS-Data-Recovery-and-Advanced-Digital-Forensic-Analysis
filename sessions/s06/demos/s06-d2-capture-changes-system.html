WHAT YOU JUST SAW

Two different things happened. The tool took memory for itself and overwrote old data: that is its footprint, and the tool even appears in its own image. And the computer kept working during the copy, so the image holds pages from different moments that do not fully agree: that is smear. The hash value was calculated when the copy ended, so it proves only that the file has not changed since then. In a case, the content of a memory image rests on the examiner's record of the tool, the time and each action.
