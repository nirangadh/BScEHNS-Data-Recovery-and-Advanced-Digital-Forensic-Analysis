What this shows: each kind of evidence has its own lifetime, so every action and every minute of waiting destroys a different layer, starting with the shortest-lived.

WHAT YOU JUST SAW

Evidence does not all last equally long. Waiting cost the network state and part of memory. Pulling the plug cost all of memory. A normal shut-down cost memory and changed the disk as well. The order of volatility, set out in RFC 3227, answers this by collecting from the most volatile to the least: memory and network state first, the disk later, backups last. In a case, the first minutes at a running computer decide which evidence will ever exist.
