WHAT YOU JUST SAW

The list walk follows the kernel's own chain, so it shows exactly what the kernel still links. The scan tests every position in memory, so it also finds a record that was taken out of the chain: an ended process whose bytes remain, or a running process that was hidden. And when memory is reused, even the scan finds nothing. In a case you run both views, and you treat a difference between them as a question to answer with the exit time, the threads and the rest of the evidence.
