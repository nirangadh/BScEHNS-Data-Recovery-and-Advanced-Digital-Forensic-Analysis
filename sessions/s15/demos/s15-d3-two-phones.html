WHAT YOU JUST SAW

Android named each app's folder after its package name, so the path told you the app, even when the label on the screen hid it. The iPhone named each data container with a generated ID, and only the metadata file inside linked it to the app's bundle identifier; a reinstall replaced the ID and removed the old data.

These are sections 4 and 5 of the notes. In a report, name the app by its package name or bundle identifier, never by a generated ID alone, and say how you linked the folder to the app.
