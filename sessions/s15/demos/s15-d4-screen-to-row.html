S15-D4: From the screen to the row

What this shows: one visit on the phone's screen is traced to a file, a table, a row and a number, and the number becomes a time in UTC only when you know which clock wrote it.

1. THE SCREEN

mlb.com

Typed in Opera on 13 July 2024, 16:12 by the researcher's notes, which use Eastern Daylight Time, UTC-4

2. THE FILE

Dump/data/data/com.opera.browser/app_opera/History

A SQLite database, as in Chrome

3. THE TABLE

urls

One row per address, with a visit count, a typed count and the last visit time

4. THE ROW

id 1 | https://mlb.com/ | typed_count 1 | last_visit_time 13365375162964931

Keyboard: the left and right arrow keys move between steps.

WHAT YOU JUST SAW

One act on the screen, typing an address, was followed into one file, one table, one row and one number. The number became a time only after you knew its clock: microseconds since 1601 in UTC, converted to 20:12:42 UTC, which agrees with the researcher's 16:12 at UTC-4.
