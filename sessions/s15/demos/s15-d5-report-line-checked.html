S15-D5: A report line, checked

What this shows: a parser's report line is compared with the value in the source file, and the check shows what the parser added that the source never held.

THE REPORT LINE (ALEAPP)

Calculator Lock - Notes

Note Date: 2024-02-04 00:00:00+00:00

Note Date (as stored): 04-02-2024

Title: My Secret Note

THE SOURCE (READ-ONLY)

.../com.calculator.lock.hide.photo.video/databases/note_contact.db

Table Note, column note_date, type TEXT

note_date = '04-02-2024'

THE RESEARCHER'S RECORD

Note "My Secret Note" created on 4 February 2024 at 12:41

12:41 at UTC-5 (Eastern Standard Time) = 17:41 UTC

Keyboard: the left and right arrow keys move between steps.

WHAT YOU JUST SAW

A report line said midnight UTC. The source file, opened read-only, held only the text 04-02-2024: a date, written day first, with no time and no clock. The parser had added midnight to sort the row, and the researcher's record put the note at 17:41 UTC; the date is also only the date of the latest save.

This is section 9 of the notes. Use the report to find evidence and the source file to state it. In the lab you check two report lines yourself, and the "If you have time" task repeats this one.
