S15-D1: Three extractions, one phone

What this shows: each kind of extraction reaches a deeper layer of the same phone, and the deepest layer comes back as unreadable data when the keys stay on the phone.

THE TEST PHONE'S STORAGE, AS THREE LAYERS

1. What the phone is designed to share

A backup: contacts, the phone's own messages and call log, photos, the data of apps that allow backup

2. Every file of the user data

Each app's private folder: its databases, settings and keys, such as Threema's and Opera's

3. The raw storage

Every block of the chip, including space no file uses, as it is stored: encrypted

WHAT THE EXTRACTION HOLDS

    Keyboard: the left and right arrow keys move between steps.

    WHAT YOU JUST SAW

    The same phone gave three different extractions. The logical one reached only what the phone shares; the full file system one reached every file of the user data, readable because the running phone decrypted them; the physical one reached every block, but encrypted, because the keys never leave the phone.

    This is section 2 of the notes. Before you read an extraction, write down its kind, because the kind decides what you can and cannot find in it. The test phone's extraction is a full file system extraction.
