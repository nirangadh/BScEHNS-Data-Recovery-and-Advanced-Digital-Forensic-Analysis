WHAT YOU JUST SAW

Each mail server added its line at the top, so you walked the route from the bottom line up: the sender's machine, then three servers. Every server wrote its own clock with its own offset, and only after normalising each one to UTC could you see that the hops followed each other within seconds. The sender's Date line, written by the sender's own clock, could then be tested against the first server's time.

This is section 3 of the notes. In the investigation, server lines give times from clocks the suspect could not touch, and they show the route; you still trust each line only as far as you trust the server that wrote it.
