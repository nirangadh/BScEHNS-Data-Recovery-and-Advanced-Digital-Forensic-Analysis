S14-D4: One visit, two records

What this shows: a browser and a web server each record the same visit with different fields, and a page shown from the cache appears in one record and not in the other.

Keyboard: the left and right arrow keys move between steps.

WHAT YOU JUST SAW

One visit produced one browser record and three server lines; one download produced a record on each side, each with fields the other lacked; and a reload from the cache produced a browser visit with only a short 304 line on the server, or none at all. You joined the pairs by path and time, because the two records share no request ID, and read the steady difference as two clocks.

This is section 7 of the notes, and Session 13's two-record idea on the open web. When both records exist, each confirms the other; when one is missing, look first at the cache, the address and the clocks.
