WHAT YOU JUST SAW

One message passed through four states: listed in its folder, moved to Deleted Items, removed from the index with its blocks still in the file, and overwritten. At each state, the tools that read only the index saw less than the tool that also searches the file's free space, and readpst with its default options did not even show Deleted Items.

This is section 5 of the notes: Session 2's lesson that deletion removes the pointer, not the data, inside a single file. In the lab you run readpst twice and pffexport once, and you record which tool showed each message, because a missing message in one tool's list is not a missing message in the store.
